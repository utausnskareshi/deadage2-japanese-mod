# Dead Age 2 日本語化パッチ（非公式）

Steam 版 **Dead Age 2** の画面表示と会話を日本語にする、非公式のファン制作パッチです。

- ボタン 1 つで日本語化でき、同じボタンでいつでも元に戻せます。
- 日本語化の前に、書き換えるゲームのファイルをバックアップします。「元に戻す」では、そのバックアップから元の状態に戻します。
- ゲーム内の言語の一覧では、「中国語（簡体字）」の枠が「日本語 (JA)」に置き換わります。

> **ご注意**
> このパッチは、Dead Age 2 の開発元・販売元の公式のものではありません。利用は自己責任でお願いします。
> 本パッチについて、ゲームの開発元・販売元へ問い合わせないでください。

## 動作環境

- Windows 10 / 11（64bit）
- Steam 版 Dead Age 2（動作確認: ビルド 20299076。ベータ版のブランチでは確認していません）
- 追加のランタイムなどのインストールは不要です（必要なものは同梱しています）。
- 日本語化の作業中は、一時的に最大で約 2.6 GB の空き容量を使います（主に C ドライブ）。
  作業後も、バックアップとして約 300 MB を使います。

## 使い方

1. [Releases](https://github.com/utausnskareshi/deadage2-japanese-mod/releases) から最新の配布 ZIP をダウンロードし、**すべて展開**します（ZIP の中から直接実行しないでください）。
2. ゲームが起動している場合は終了します。
3. `DeadAge2JPPatcher.exe` を実行します。
   - ゲームがインストールされていない場合は、その旨を表示して終了します。
4. **「日本語化する」** を押します。数十秒ほどで終わります。
5. Steam からゲームを起動すると、日本語で表示されます。

画面にある 2 つのチェックは、どちらもオンのまま使ってください。

- **日本語フォント（BIZ UDPゴシック）で表示する**: ゲームが中国語の表示に使うフォントを、日本語のフォントに差し替えます。
- **ゲームの言語設定を自動で「日本語 (JA)」に切り替える**: ゲームの設定ファイルの言語を「日本語 (JA)」にします。
  ゲームを一度も起動していない場合は設定ファイルが無いため、切り替えられません。
  ゲーム内の「オプション」→ 言語で「日本語 (JA)」を選んでください。

### 元に戻す

もう一度 `DeadAge2JPPatcher.exe` を実行し、**「元に戻す」** を押します。
バックアップから元のファイルに戻し、自動で切り替えた言語設定も元に戻します。

### 初回実行時の警告について

このツールにはコード署名が無いため、初回実行時に「Windows によって PC が保護されました」と表示されることがあります。
「詳細情報」→「実行」で起動できます。ZIP が改ざんされていないかは、同時に配布している `.sha256` の値と
ZIP の SHA-256 を比べて確認できます。

```powershell
Get-FileHash .\DeadAge2JP-v1.0.0.zip -Algorithm SHA256
```

## 日本語化される範囲

- メニュー、アイテム、スキル、クエスト、ゲーム中のメッセージなどの画面表示（2,329 件）
- 登場人物との会話（4,559 件）

次のものは日本語化されません。

- 画像として描かれた文字（ロゴなど）
- ゲームの更新で新しく追加された文言（訳が追加されるまで、英語で表示されます）

## 注意事項

- **ゲームの更新**: Steam でゲームが更新されると、日本語化が外れることがあります。
  ツールを起動して「ゲームの更新で日本語化が外れています」と表示されたら、もう一度「日本語化する」を押してください。
  「一部のファイルだけ日本語化されています」と表示されたら、「元に戻す」を押してから「日本語化する」をやり直してください。
- **書き換えるファイル**: ゲームフォルダの `DeadAge2_Data\data.unity3d` と `AssetBundles\prefabs` の 2 つです。
  書き換える前のファイルは `%LOCALAPPDATA%\DeadAge2JP\backup` に保存します。
- **セーブデータ・設定**: セーブデータには手を加えません。ゲームの設定ファイル（`settings.json`）は、言語の項目だけを書き換えます
  （言語を切り替えるチェックを外した場合は、書き換えません）。
- **中国語（簡体字）**: 日本語化している間は、その枠を日本語に使うため、中国語（簡体字）では遊べません。
- **翻訳の作成方法**: 翻訳は AI（Claude）を用いて作成し、用語の統一と機械的な検証、ゲーム画面での表示確認を行っています。
  誤訳や不自然な表現が残っている可能性があります。修正の提案を歓迎します。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「インストールが見つかりませんでした」と表示される | Steam 版がインストール済みか確認してください。Steam 以外の版には対応していません。 |
| 「起動中です」と表示される | ゲームを終了してから、もう一度実行してください。 |
| 「Steam でゲームの更新またはダウンロードが完了していないようです」と表示される | Steam で更新を済ませてから、もう一度実行してください。 |
| 「書き込む権限がありません」と表示される | 表示に従って、管理者として起動し直してください。 |
| 「空き容量が足りません」と表示される | 表示されたドライブの空き容量を増やしてから、もう一度実行してください。 |
| 日本語にならない | ゲーム内の「オプション」→ 言語で「日本語 (JA)」が選ばれているか確認してください。 |
| そのほかのエラー | 画面の「ログフォルダを開く」で開くフォルダ（`%LOCALAPPDATA%\DeadAge2JP\logs`）のログを添えて報告してください。 |

Steam のライブラリで Dead Age 2 を右クリック →「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を実行しても、
ゲームのファイルを元の状態に戻せます。この方法ではゲームの言語設定は戻らないため、ゲーム内の「オプション」→ 言語で選び直してください。

## 仕組み

- ゲームの文言は、`DeadAge2_Data\data.unity3d` の中の 2 つの表（画面表示と会話）にまとめて入っています。
  ツールは、表の「中国語（簡体字）」の列を日本語訳に置き換えます。訳の無い文言には、英語をそのまま入れます。
- 日本語の文字は、ゲームが中国語の表示に使うフォントの中身を BIZ UDP ゴシックに差し替えて表示します。
  表示する文字の種類が多いため、フォントの文字画像（アトラス）を複数枚使えるように設定を変えます。
  同じフォントを持つ `AssetBundles\prefabs` も、同じように書き換えます。
- 書き換えの前後のファイルのハッシュとバックアップの場所を、`%LOCALAPPDATA%\DeadAge2JP\state.json` と
  ゲームフォルダの `DeadAge2_Data\DeadAge2JP.state.json` に記録します。状態の判定と「元に戻す」に使います。
- 訳のファイルには、ゲーム内部のキー名と日本語訳だけを収録しています。英語の原文は、日本語化するときに利用者のゲームのファイルから読み取ります。

## 翻訳の修正に協力する

訳は [translations](translations) にあります。`ui` が画面表示、`dialogue` が会話です。

```json
"Button_Accept": {
  "text": "決定",
  "source": "89713b9c9c1b8f65"
}
```

- `text` が日本語訳です。`source` は、訳したときの英語原文を識別する値（ハッシュ値）で、原文そのものは含みません。
- `{0}` などの書式指定子、`[Player]` などの角括弧の差し込み、`<b>` などのタグは、原文と同じものを残してください。
- 配布 ZIP の `data\translations` の中のファイルを書き換えてから「日本語化する」を実行すると、修正を試せます
  （日本語化済みの場合は、先に「元に戻す」を押してください）。

## ビルド方法

必要なもの: Windows、.NET SDK 10

```powershell
powershell -ExecutionPolicy Bypass -File build\build-release.ps1
```

`out` フォルダに、配布用 ZIP（`DeadAge2JP-v<版>.zip`）と、その SHA-256 を記した `.sha256` ファイルが作られます。

| フォルダ | 内容 |
|---|---|
| `src/DeadAge2JP.Patcher` | パッチツールの画面（WPF） |
| `src/DeadAge2JP.Core` | パッチツールの中核（Steam の検出、ゲームのファイルの読み書き、適用・元に戻す） |
| `translations` | 日本語訳（画面表示と会話） |
| `assets` | 日本語フォント、Unity の型情報データベース、第三者ソフトウェアのライセンス文 |
| `build` | 配布用 ZIP を作るスクリプト |
